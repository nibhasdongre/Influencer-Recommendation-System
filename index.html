The problem

Popularity is not the same as relevance or credibility.

Follower-count and keyword-based discovery can miss whether a creator's content actually fits a campaign — and whether engagement signals look reliable. This project explores a ranking approach that considers multiple signals together.

What the system aims to do

Given a brand brief (and optionally a reference image), retrieve creators whose content is semantically aligned with the campaign, then refine the candidate ranking using trust and engagement-anomaly signals.

  • Relevance: understand creator text and visual content.
  • Trust: use creator-graph relationships and verification signals.
  • Risk: flag unusual engagement patterns for ranking/filtering.

Dataset snapshot

The implemented research dataset contains creator profiles collected from two social platforms and a labelled verification subset used by the graph model.

  • 2,960 creator profiles across YouTube and Instagram.
  • 99 verified creator accounts in the graph dataset.
  • ~59,450 bidirectional graph edges across four relationship types.
  • 450 query–creator pairs in the custom evaluation benchmark.
System pipeline

Three signals. One ranked shortlist.

The pipeline is retrieval-first: semantic similarity finds relevant candidates; trust and anomaly signals then help refine the shortlist.

Collect & prepare

Gather creator, post/video, metric and thumbnail data; clean and join platform records.

YouTube Data API · Apify · Pandas

Encode content

Encode creator text and images separately, normalise each modality and combine them.

CLIP ViT-B/32 · 1,024 dimensions

Learn trust & risk

Build a multi-relational creator graph and train platform-specific engagement autoencoders.

GraphSAGE · PyTorch autoencoders

Retrieve candidates

Search the creator embedding index using text or text-plus-image campaign queries.

FAISS · IndexFlatIP

Re-rank results

Apply domain-aware ranking with trust signals and anomaly penalties to produce a shortlist.

My contribution

Data pipelines, graph learning and anomaly detection.

The project was developed as a team effort. My primary contributions focused on data engineering and the graph-learning / anomaly-detection components.

Data engineering

Cross-platform data pipeline

Built the collection and preprocessing workflow using the YouTube Data API and Apify Instagram data, with local persistence, scheduling and creator-level feature preparation.

Graph machine learning

GraphSAGE trust modelling

Developed the creator graph and GraphSAGE-based trust model, using relationship signals and verification labels to derive creator trust scores.

Anomaly detection

Engagement anomaly models

Engineered engagement features and implemented separate PyTorch autoencoders for YouTube and Instagram to identify unusual engagement patterns.

Team integration

End-to-end recommendation pipeline

Worked with the team integrating the data, trust and anomaly outputs into a multimodal retrieval and re-ranking system evaluated against ranking baselines.
